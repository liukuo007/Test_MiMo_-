## 一、 产品类型与应用场景

视达提供多种组合的智能售货终端，满足不同的零售需求：

1. **饮料智能售货柜**：支持单门、双门及多组合形式。
2. **零食饮品售货柜**：支持灵活陈列，可将零食与饮料等多种品类混合售卖，打造综合零售终端。
3. **烘焙食品售货柜**：支持将烘焙或烹饪食物（如三明治、沙拉、便当等）与饮料和咖啡打包售卖。
4. **冷冻食品售货柜**：可售卖冰激凌、冷冻食材、预制食材等商品。

## 二、 核心技术与产品优势

### 1. 视达商品识别大模型（“多、快、好、省”）
* **多**：可识别商品种类丰富，涵盖零售、饮品、便当、沙拉、营养保健品、冰激凌、玩具、文创商品、预制菜等。
* **快**：端计算辅助真 AI，识别过程完全在设备端完成，整个过程在 **3 秒内**完成。
* **好**：历时 1000 万小时的数据积累和模型优化，准确度达 **99% 以上**，货损低至 **0.5% 以内**。
* **省**：真 AI 识别，每笔订单识别费用至少节约 **40%**；无需寄送商品，**10 分钟**即可完成新商品学习与上架。

### 2. 视达软件平台
* **开放与集成能力**：提供丰富的 API 接口，支持灵活的对接需求。
* **安全稳定**：自研 VMS 平台架构及完善的备份措施，保证云平台 SLA 达 **99.99%**。
* **隐私保护**：自动人脸模糊，不收集和识别个人生物特征信息，不上传或存储个人数据。
* **组织管理**：支持组织层级管理，满足大中小不同体量客户的管理需求。

### 3. 视达硬件系统（稳如磐石）
* **强劲算力**：搭载 8 核处理器，提供 **6T 算力**，支持订单秒结等高速计算。
* **工业级相机**：

  * 配备 **星光级 AI 相机**，无惧暗光环境，稳定不掉线。
