1. 业务背景
核心技术：公司主营业务包含视觉识别（AI 视觉）。

应用场景：智能货柜。用户开门拿取商品后，系统通过摄像头识别商品并自动生成订单。

商业模式：设备销往海外，由当地的运营商负责购买设备、组建团队并进行铺货和销售。

2. 现有系统架构
整个系统链路较长，包含以下主要模块：

硬件终端：包含货柜物理设备、摄像头、门控系统、锁控系统，以及部署在设备上的基础软件和计算单元（CPU/GPU等）。

网络与物联网 (IoT)：物理设备通过长连接接入 IoT 服务器集群。

SaaS 服务端：IoT 集群与后端 SaaS 业务系统进行通讯交互。

前端应用：提供给运营商和用户的各类端侧应用，包括 Web 网页、移动端 App、H5 管理界面等。

第三方集成：对接外部的短信网关、支付系统、SSO（单点登录）等服务。

3. 核心痛点与挑战
规模剧增：公司业务飞速扩张，物理设备数量呈指数级增长（达到数万台）。

测试瓶颈：面对激增的设备量和复杂的系统链路，现有的测试手段（可能依赖人工或单点测试）效率低下，已无法支撑业务发展。

4. 您的考核任务
任务目标：设计一套端到端的全链路测试系统（或测试平台），以解决现有测试效率低下的问题。

角色定位：不要把自己当成被动的执行者或面试者，而要以“平台负责人”或“公司架构师”的视角（Owner 意识）来主导这次设计。

覆盖范围：平台需要能够覆盖从物理设备、IoT网关、SaaS后台、前端应用到第三方接口的全方位测试。

5. 最终交付物要求
系统原型/演示 (Demo)：需提供一套可视化的工具设计或平台原型。

功能说明：明确指出该测试平台具备哪些核心功能。

使用流程：清晰描述日常测试中应如何操作和使用这套工具。

技术不设限：在设计阶段，不需要考虑现有底层技术是否能完美实现，重点在于平台架构的思想、功能的完整性以及解决问题的逻辑。
