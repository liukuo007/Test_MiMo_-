# API 文档

启动后端服务后，访问以下地址查看自动生成的 API 文档：

- Swagger UI: http://localhost:8100/docs
- ReDoc: http://localhost:8100/redoc

## API 概览

| 模块 | 前缀 | 说明 |
|------|------|------|
| 认证 | /api/v1/auth | 登录、注册 |
| 用户 | /api/v1/users | 用户管理 |
| 项目 | /api/v1/projects | 项目管理 |
| 设备 | /api/v1/devices | 设备管理 |
| 用例 | /api/v1/test-cases | 用例管理 |
| 任务 | /api/v1/test-tasks | 任务编排 |
| 结果 | /api/v1/test-results | 测试结果 |
| AI | /api/v1/ai | AI 验证 |
| Trace | /api/v1/traces | 链路追踪 |
| 看板 | /api/v1/dashboard | 数据看板 |
